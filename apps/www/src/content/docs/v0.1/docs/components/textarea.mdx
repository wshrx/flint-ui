## Usage

```tsx
import { Textarea } from "@/components/ui/textarea"

<Textarea
  value={about}
  onChange={(event) => setAbout(event.value ?? "")}
  minRows={3}
  maxRows={8}
/>
```

## Notes

Rows are counted by GPUI, not by a `rows` attribute. Past `maxRows` the editor scrolls inside the
surface; the wrapper does not grow, so a long paste cannot push the footer off screen.
