## Usage

```tsx
import {
  Card, CardHeader, CardTitle, CardDescription, CardContent, CardFooter,
} from "@/components/ui/card"

<Card>
  <CardHeader>
    <CardTitle>Profile</CardTitle>
    <CardDescription>How the workspace appears to people you invite.</CardDescription>
  </CardHeader>
  <CardContent>{/* fields */}</CardContent>
  <CardFooter>
    <Button variant="outline" size="sm">Export</Button>
  </CardFooter>
</Card>
```

## Variants

| `variant` | Surface | Use for |
| --- | --- | --- |
| `default` | `card` fill, hairline border | most panels |
| `inset` | `muted` fill, no border | a block inside another surface |
| `outline` | transparent, hairline | a preview or an empty slot |

## Notes

* `CardFooter` draws its own top hairline. Do not add a separator.
* A card inside a card is always wrong. If you need a group inside a card, use a heading and a
  hairline, or switch the inner block to `inset`.
* The card has no shadow. Depth is reserved for surfaces that float above the page: menus, dialogs
  and the tooltip.
