## Usage

```tsx
import { Switch } from "@/components/ui/switch"

const [beta, setBeta] = useState(false)

<div style={{ display: "flex", alignItems: "center", gap: 10 }}>
  <Switch checked={beta} onCheckedChange={setBeta} />
  <Text>Beta channel</Text>
</div>
```

## Notes

A switch applies its change immediately; a checkbox is a value you submit later. If the setting needs
a Save button, use `Checkbox`.

The thumb moves by `justifyContent`, not by an animated offset: GPUIX motion cannot animate a
transform, and a 120ms jump between two states reads better than a tween that never lands.
