## Usage

```tsx
import { Label } from "@/components/ui/label"
import { Text } from "@/lib/flint"

<Label required>Workspace name</Label>
<Input value={name} onChange={(event) => setName(event.value ?? "")} />
<Text size="xs" tone="muted">Shown to everyone you invite.</Text>
```

## Notes

GPUI has no `for=`, so a label is not programmatically tied to a field. Give the field an
`aria-label` as well when the label is not the only thing naming it. The required mark is drawn,
not announced; put "required" in the hint text if the form is long.
