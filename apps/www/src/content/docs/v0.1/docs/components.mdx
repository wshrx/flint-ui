Twelve components, seven shared primitives, no runtime to keep in sync. Each page shows the
rendered component, the exact file `flint-ui add` writes, and every prop.

The previews on every component page are **live**, not screenshots. The page runs the real GPUIX
renderer through WebGPU in an iframe, and Astro's router keeps that iframe alive across navigation:
the 20 MB wasm module is fetched and compiled once per visit, then only the demo changes. If the
browser cannot create a GPU surface, the preview says so and the source below is still the same
file that would have run.

## Shared primitives

`flint-ui init` copies these once. Components depend on them; you rarely import them directly,
except `Text` and `Icon`.
