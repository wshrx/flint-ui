## Usage

```tsx
import { Tooltip, TooltipTrigger, TooltipContent } from "@/components/ui/tooltip"
import { Button } from "@/components/ui/button"
import { Icon } from "@/lib/flint"

<Tooltip>
  <TooltipTrigger asChild>
    <Button variant="ghost" size="icon" aria-label="Remove">
      <Icon name="minus" />
    </Button>
  </TooltipTrigger>
  <TooltipContent>Remove from workspace</TooltipContent>
</Tooltip>
```

## Notes

- The surface is inverted: `foreground` fill, `background` text. That is the one place a large block
  of the text colour is used as a background, and it is why the tooltip needs no border.
- Keep it to one line. Anything longer belongs in the interface, not in a tooltip.
- The trigger needs its own accessible name. A tooltip is a hint, not a label — pass `aria-label` on
  icon-only buttons.
