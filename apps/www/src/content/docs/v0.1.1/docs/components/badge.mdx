## Usage

```tsx
import { Badge } from "@/components/ui/badge"

<Badge>Owner</Badge>
<Badge variant="secondary">Editor</Badge>
<Badge variant="outline">MIT</Badge>
<Badge variant="destructive">Failed</Badge>
<Badge variant="success" dot>Connected</Badge>
```

## Notes

The badge is 20px tall with 11px text. Numerals inside a badge use the same font as the label; do not
switch to mono for a count, or a row of badges will jitter. `success` is the only non-ember colour in
the palette, and it is reserved for live state — not for decoration.
