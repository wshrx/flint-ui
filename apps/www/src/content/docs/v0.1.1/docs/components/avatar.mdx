## Usage

```tsx
import { Avatar } from "@/components/ui/avatar"

<Avatar src="./photos/ada.png" name="Ada Lovelace" />
<Avatar name="Grace Hopper" />
<Avatar name="Grace Hopper" size={24} />
```

## Notes

`src` takes a filesystem path, a data URL or an http(s) URL, and the image is cropped with
`objectFit="cover"` — a portrait never squashes into the circle. Without `src` the first letters of
the first two words are painted on the muted surface, which is the normal state, not a failure.

The fallback is upper-cased and capped at two characters. A single word gives its first two
letters; nothing gives `?`.
