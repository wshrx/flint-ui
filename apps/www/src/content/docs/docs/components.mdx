Twenty-three components, seven shared primitives, no runtime to keep in sync. Each page shows the
rendered component, the exact file `flint-ui add` writes, and every prop.

There is no live preview: the components are native, and the docs ship the source.

## Shared primitives

`flint-ui init` copies these once. Components depend on them; you rarely import them directly,
except `Text` and `Icon`.

<dl class="flint-catalog">
  <div>
    <dt><code>lib/flint/theme.ts</code></dt>
    <dd><code>flintDark</code>, <code>flintLight</code>, <code>inputTheme</code>: the tokens.</dd>
  </div>
  <div>
    <dt><code>lib/flint/theme-provider.tsx</code></dt>
    <dd><code>ThemeProvider</code> and <code>useTheme</code>: one palette per window.</dd>
  </div>
  <div>
    <dt><code>lib/flint/utils.ts</code></dt>
    <dd><code>mergeStyle</code> and <code>mergeStyles</code>: the object <code>cn()</code>.</dd>
  </div>
  <div>
    <dt><code>lib/flint/text.tsx</code></dt>
    <dd><code>Text</code>: text that cannot be black by accident.</dd>
  </div>
  <div>
    <dt><code>lib/flint/icon.tsx</code></dt>
    <dd><code>Icon</code>: monochrome SVG at a given size.</dd>
  </div>
  <div>
    <dt><code>lib/flint/use-controllable.ts</code></dt>
    <dd><code>useControllableState</code>: controlled and uncontrolled parity.</dd>
  </div>
  <div>
    <dt><code>lib/flint/fonts.ts</code></dt>
    <dd><code>registerFlintFonts</code>: Medeo into the process.</dd>
  </div>
</dl>
