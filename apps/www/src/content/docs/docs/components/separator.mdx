## Keyboard and accessibility

The unlabelled separator is a `div` with `role="separator"`, so a screen reader is told there is a
boundary. It is not focusable and has no keys.

A separator with `label` returns a flex row instead, so it carries no role. The label is read as
plain text between two lines.

## When not to use it

Use a heading to split a long page; a line between every section is noise. Inside a list, spacing
or a `Card` separates rows without another element. Reach for a separator when two blocks would
otherwise touch.

## Notes

A horizontal separator is one pixel of `border` and takes the full width. The vertical one
stretches to the height of its row, so it needs a parent with a height. Inside a line of text it
collapses to nothing.

`label` only applies horizontally and renders at 11 px in `mutedForeground`. It is a section break,
not a heading: do not put a label on a separator that already sits under a heading.
