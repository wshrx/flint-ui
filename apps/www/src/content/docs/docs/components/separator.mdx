## Usage

```tsx
import { Separator } from "@/components/ui/separator"

<Separator />

<Separator label="or" />

<div style={{ display: "flex", alignItems: "center", gap: 12, height: 24 }}>
  <Text>Left</Text>
  <Separator orientation="vertical" />
  <Text>Right</Text>
</div>
```

## Notes

A horizontal separator is one pixel of `border` and takes the full width. The vertical one
stretches to the height of its row, so it needs a parent with a height — inside a line of text it
collapses to nothing.

`label` only applies horizontally and renders at 11 px in `mutedForeground`. It is a section break,
not a heading: do not put a label on a separator that already sits under a heading.
