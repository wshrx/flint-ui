## Usage

```tsx
import { useState } from "react"
import { Switch } from "@/components/ui/switch"
import { Text } from "@/lib/flint"

const [beta, setBeta] = useState(false)

<div style={{ display: "flex", alignItems: "center", gap: 10 }}>
  <Switch checked={beta} onCheckedChange={setBeta} aria-label="Beta channel" />
  <Text>Beta channel</Text>
</div>
```

## Notes

A switch applies its change immediately; a checkbox is a value you submit later. If the setting needs
a Save button, use `Checkbox`.

The thumb moves by `justifyContent`, not by an animated offset: GPUIX motion cannot animate a
transform, and a 120ms jump between two states reads better than a tween that never lands.

## Keyboard and accessibility

`Switch` renders a focusable track with `role="switch"`; Space or Enter toggles it, and a disabled
switch gets `tabIndex={-1}`. There is no `aria-checked` in the host props, so the on and off state
is visual only; give the switch an `aria-label` and state the current value in nearby text. Focus
is a 2px `ring` outline offset by 2px.
