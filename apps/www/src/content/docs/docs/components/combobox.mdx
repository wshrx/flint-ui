## Usage

```tsx
import {
  Combobox,
  ComboboxContent,
  ComboboxEmpty,
  ComboboxInput,
  ComboboxItem,
  ComboboxList,
} from "@/components/ui/combobox"

const roles = ["Viewer", "Editor", "Admin", "Billing", "Owner"]

<Combobox items={roles} defaultValue="Editor">
  <ComboboxInput placeholder="Search roles" />
  <ComboboxContent>
    <ComboboxList>
      {(item) => <ComboboxItem value={item}>{item}</ComboboxItem>}
    </ComboboxList>
    <ComboboxEmpty>No role matches that.</ComboboxEmpty>
  </ComboboxContent>
</Combobox>
```

## Notes

The input is the trigger: typing filters the list, arrows move the highlight, Enter picks the
highlighted item and Escape closes. That behaviour is `@gpuix/react`'s `Combobox`, not a key
handler here; flint only supplies the surface, the check mark and the empty state.

Use it when the list is long enough that scanning a select is work — roles, people, time zones.
For five fixed options a `Select` is faster, and for a free-form value a plain `Input` is honest.

`children` of `ComboboxItem` is a string on purpose: it is painted through `<Text>`, so the label
takes the theme colour instead of GPUI's default black. Put an icon in the item's trailing slot
by wrapping the primitive directly if you need one.
