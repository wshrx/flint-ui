## Usage

```tsx
import { Tabs, TabsList, TabsTrigger, TabsContent } from "@/components/ui/tabs"

const [tab, setTab] = useState("general")

<Tabs value={tab} onValueChange={setTab}>
  <TabsList>
    <TabsTrigger value="general">General</TabsTrigger>
    <TabsTrigger value="members">Members</TabsTrigger>
  </TabsList>
  <TabsContent value="general">{/* … */}</TabsContent>
  <TabsContent value="members">{/* … */}</TabsContent>
</Tabs>
```

`TabsList variant="line"` puts the strip on a hairline instead of a filled track, for settings pages
where the tabs sit under a heading.

## Notes

Inactive panels are **unmounted**, not hidden. That is deliberate: a panel with an input should not
keep state the user cannot see, and it keeps cost proportional to what is on screen. If you need a
panel to stay mounted, render it yourself and toggle `visibility`.
