## Usage

```tsx
import { useState } from "react"
import { Label } from "@/components/ui/label"
import { Input } from "@/components/ui/input"
import { Text } from "@/lib/flint"

const [name, setName] = useState("")

<Label required>Workspace name</Label>
<Input
  value={name}
  onChange={(event) => setName(event.value ?? "")}
  aria-label="Workspace name"
/>
<Text size="xs" tone="muted">Shown to everyone you invite.</Text>
```

## Notes

GPUI has no `for=`, so the visible label never names the field programmatically. Always give the
control its own accessible name with `aria-label`. The required mark is drawn, not announced; say
"required" in the field's name or hint.

## Keyboard and accessibility

`Label` is a text node with no role and no tab stop, so it cannot name a control. The control must
carry `aria-label`; the visible label is positional only, so keep it directly above that control.
