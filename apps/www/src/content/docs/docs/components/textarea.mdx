## Usage

```tsx
import { useState } from "react"
import { Textarea } from "@/components/ui/textarea"

const [about, setAbout] = useState("")

<Textarea
  value={about}
  onChange={(event) => setAbout(event.value ?? "")}
  minRows={3}
  maxRows={8}
  aria-label="About"
/>
```

## Keyboard and accessibility

Focus is tracked on the native editor by `onFocus` and `onBlur`, and the wrapper paints the `ring`
border and a 2px outline. Enter inserts a newline; set `onSubmit` if you also need a submit event
on Enter. The field grows from `minRows` to `maxRows` and scrolls inside the surface after that.
Give it an `aria-label`: there is no `for=`, so a visible `Label` does not name it programmatically.

## Notes

Rows are counted by GPUI, not by a `rows` attribute. Past `maxRows` the editor scrolls inside the
surface; the wrapper does not grow, so a long paste cannot push the footer off screen.
