## Usage

```tsx
import { Button } from "@/components/ui/button"
import { Icon } from "@/lib/flint"

<Button>Save changes</Button>
<Button variant="secondary">Cancel</Button>
<Button variant="outline" size="sm">Export</Button>
<Button variant="destructive">Delete</Button>
<Button variant="ghost" size="icon" aria-label="Toggle sidebar">
  <Icon name="panelLeft" />
</Button>
```

`asChild` passes the props to the single child instead of wrapping it, which is how a dialog
trigger becomes a button.

## Variants

| `variant` | Surface | Use for |
| --- | --- | --- |
| `primary` | primary fill | the one action on the screen |
| `secondary` | raised neutral | secondary actions next to a primary |
| `outline` | transparent, hairline | neutral actions in a toolbar |
| `ghost` | transparent | icon buttons, list rows |
| `destructive` | red fill | irreversible actions |
| `link` | text only | inline navigation |

## Sizes

`sm` 28px · `md` 32px · `lg` 38px · `icon` 32×32. Heights are px numbers, not rem: GPUIX has no
root font size to scale against.

## Notes

- `loading` keeps the label, dims the surface and paints a 10 px dot before it. There is no
  spinner: GPUIX motion has no rotation. `asChild` with `loading` keeps the child and skips the
  dot, because the child owns the markup.
- Disabled buttons are removed from the tab order. Pass `focusableWhenDisabled` through if the
  button is disabled while saving and should still be reachable.

## Keyboard and accessibility

`Button` renders a focusable element with `role="button"`. Enter fires on key down and Space on key
up, and both stop when a handler calls `preventDefault`. A disabled button gets `tabIndex={-1}` and
leaves the tab order, and the code sets no `aria-disabled`, so keep the reason in nearby text. Focus
is a 2px `ring` outline offset by 2px, so it takes no layout space.

## When not to use it

Use a link for navigation and a plain text label for static state.
