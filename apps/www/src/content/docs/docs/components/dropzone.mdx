## Usage

```tsx
import { Dropzone } from "@/components/ui/dropzone"

<Dropzone
  accept={[".png", ".jpg"]}
  hint="PNG or JPG, up to 10 files"
  onFiles={(paths) => addImages(paths)}
/>

<Dropzone disabled hint="Finish the upload first">
  Drop a replacement here
</Dropzone>
```

## Keyboard and accessibility

A dropzone is pointer-only. GPUIX reports the drop, not a keyboard equivalent, so pair it with a
button or an input that reaches the same action. The area has no role and no tab stop; the hint
explains what it accepts, and the button carries the accessible name.
## Notes

The drop event carries absolute filesystem paths. flint reports them and stops: no upload, no copy,
no reading. What happens next belongs to the app.

`accept` compares extensions case-insensitively. Files that do not match are dropped from the list
silently; if every file is rejected, `onFiles` is not called. That is deliberate: a drag that ends
with nothing is a smaller surprise than a modal about file types.

The active state follows the pointer, not the OS drag session. GPUIX reports the drop, not the
drag-enter and drag-leave phases, so the border lights up while the pointer is over the area rather
than only while a file is held.
