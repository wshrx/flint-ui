## When not to use it

`Kbd` is a label, not a control: it does not listen for the key. For an unfamiliar control, put the
hint in a `Tooltip` next to the icon, where the user is looking, and keep `Kbd` for the sentence
that explains the shortcut.

## Notes

One chord per element. If a shortcut is a sequence, render two `Kbd`s with a separator between
them; two chords inside one pill read as a single key.

The text is already formatted by the caller (`⌘`, `Ctrl`, `Shift`) because the right labels depend
on the platform the app runs on, and flint does not guess.
