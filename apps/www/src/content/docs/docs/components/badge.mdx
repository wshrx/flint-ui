## Keyboard and accessibility

A badge is not a control: there is no role, no tab stop and no key handler. The label is plain text,
so it is read where it appears; the status dot is decorative and carries no text. Write the state in
the label, not only in the dot.
## Notes

The badge is 20px tall with 11px text. Numerals inside a badge use the same font as the label; do not
switch to mono for a count, or a row of badges will jitter. The default tone fills with `primary`;
`success` uses the success token and is reserved for live state, not decoration.

## When not to use it

If the message needs a sentence and an action, use `Alert`; a badge holds a word or a number.
