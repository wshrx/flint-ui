## Keyboard and accessibility

The track is a `div` with `role="progressbar"` and `aria-valuetext` set to the rounded percentage,
for example `"64%"`. The code sets no `aria-label`, `aria-labelledby` or `aria-valuenow`, so the
value is announced without a name.

Put the job in `label`, or next to the bar in a heading. The bar takes no focus and has no keys.

## When not to use it

There is no indeterminate mode, on purpose. For work of unknown length, use the `Skeleton` of the
list being replaced, or the `loading` prop on the button that started the work.

A value that only moves backwards, such as a countdown, is not progress.

## Notes

The bar is 6 px tall; the label and the percentage share one line above it. Numerals inside a 6 px
track are unreadable, and a bar with text in it stops looking like a bar.

Values are clamped to `0…max`, and `max` falls back to 100 when it is zero or negative.
