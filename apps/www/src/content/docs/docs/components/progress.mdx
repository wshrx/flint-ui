## Notes

The bar is 6 px tall; the label and the percentage share one line above it. Numerals inside a 6 px
track are unreadable, and a bar with text in it stops looking like a bar.

Values are clamped to `0…max`, and `max` falls back to 100 when it is zero or negative. The
percentage is exposed with `aria-valuetext`; the label is plain text, so pair the component with a
visible heading when the number alone would not say what is progressing.

This is a determinate bar. For work of unknown length there is no indeterminate mode on purpose —
use a spinner in the button that started the work, or the `Skeleton` of the list being replaced.
