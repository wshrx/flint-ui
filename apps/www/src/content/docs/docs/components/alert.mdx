## Usage

```tsx
import { Alert } from "@/components/ui/alert"
import { Button } from "@/components/ui/button"

<Alert
  tone="destructive"
  title="Deploy failed"
  description="The build stopped at typecheck. Nothing was published."
>
  <Button size="sm" variant="outline">Open log</Button>
</Alert>

<Alert tone="success" title="Invite sent" description="alex@example.com can join now." />
<Alert tone="neutral" title="Draft" description="Only you can see this workspace." />
```

## Keyboard and accessibility

The outer `div` carries `role="alert"`, so a screen reader announces the title and description when
the alert mounts. Changing the props of a mounted alert is not a new announcement.

Focus does not move: the user keeps their place in the page. Buttons in `children` are ordinary tab
stops.

## When not to use it

For a message about one input, use the `error` prop on `Field`. When the user has to answer before
continuing, use a `Dialog`.

An alert has no close control. If the message should be dismissible, this is the wrong shape.

## Notes

The tone colours one icon and one 2 px rule on the left; the surface stays on `muted` with a
hairline. Three alerts in a row therefore read as three messages, not three alarm colours.

`children` is a row for actions, usually an outline button.
