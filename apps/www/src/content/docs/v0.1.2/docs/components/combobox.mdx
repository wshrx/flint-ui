flint-ui add combobox

## Usage

```tsx
import {
  Combobox,
  ComboboxContent,
  ComboboxEmpty,
  ComboboxInput,
  ComboboxItem,
  ComboboxList,
} from "@/components/ui/combobox"

const roles = ["Viewer", "Editor", "Admin", "Billing", "Owner"]

<Combobox items={roles} defaultValue="Editor">
  <ComboboxInput placeholder="Search roles" />
  <ComboboxContent>
    <ComboboxList>
      {(item) => <ComboboxItem value={item}>{item}</ComboboxItem>}
    </ComboboxList>
    <ComboboxEmpty>No role matches that.</ComboboxEmpty>
  </ComboboxContent>
</Combobox>
```

## Keyboard and accessibility

`ComboboxInput` is a native text input, and the keys come from `@gpuix/react`. Typing filters the
list case-insensitively, with prefix matches before substring matches.

ArrowDown and ArrowUp move the highlight and wrap around, skipping disabled items. Ctrl+N and
Ctrl+P do the same. Enter picks the highlighted item and closes the popup, Escape closes it, and
focus leaving the input closes it.

The highlight is not a cursor: focus stays in the input, and the primitive sets no
`aria-expanded`, `role="listbox"` or `role="option"`. A screen reader meets a text field and a list
of plain labels.

## When not to use it

Use it when scanning a select is work: roles, people, time zones. For five fixed options a `Select`
is faster, and for a free-form value a plain `Input` is honest.

## Notes

`children` of `ComboboxItem` is a string on purpose: it is painted through `<Text>`, so the label
takes the theme colour instead of GPUI's default black. Put an icon in the item's trailing slot by
wrapping the primitive directly if you need one.

`ComboboxContent` sets `sideOffset={6}` after the props it spreads, so a `sideOffset` you pass is
ignored. `side` and `align` do pass through.
