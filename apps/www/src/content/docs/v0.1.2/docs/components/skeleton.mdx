```bash
flint-ui add skeleton
```

## Usage

```tsx
import { Skeleton } from "@/components/ui/skeleton"

<Skeleton height={16} width={220} />
<Skeleton height={12} />
<Skeleton width={32} height={32} radius={999} />
```

## When not to use it

A skeleton stands in for a layout you already know. When one control is busy, use the `loading`
prop on its `Button`. When the work has a measurable end, use `Progress`.

Do not stack blocks for a page whose shape you cannot predict; one line of text says more.

## Notes

There is no shimmer and no pulse. A placeholder that moves reads as content that is about to
appear; two of them next to each other read as a broken layout.

Match the block to the real thing: 12 px for a line of body text, 32 px for a control, the same
radius as the surface it replaces. `aria-hidden` is set, so a screen reader skips it. Put the
loading state in the surrounding region instead.
