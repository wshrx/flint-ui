flint-ui add avatar

## Usage

```tsx
import { Avatar } from "@/components/ui/avatar"

<Avatar src="./photos/ada.png" name="Ada Lovelace" />
<Avatar name="Grace Hopper" />
<Avatar name="Grace Hopper" size={24} />
```

## Keyboard and accessibility

With `src`, the avatar is an `img` and `alt` falls back to `name`, so the accessible name is the
person's name.

Without `src` there is no image and no `alt`: the fallback is a `div` holding the initials as text.
A screen reader reads `AL`, not `Ada Lovelace`. Keep a visible name beside the avatar, or pass the
name in the surrounding text.

The avatar takes no focus and has no keys.

## When not to use it

When the name already sits next to it, an avatar adds no information and costs a request per row.
If there is no person behind the mark, use an `Icon`.

For a group, a count or a `Badge` is smaller than a row of circles.

## Notes

`src` takes a filesystem path, a data URL or an http(s) URL, and the image is cropped with
`objectFit="cover"`, so a portrait never squashes into the circle. Without `src` the first letters
of the first two words are painted on the muted surface, which is the normal state, not a failure.

The fallback is upper-cased and capped at two characters. A single word gives its first two
letters; nothing gives `?`.
